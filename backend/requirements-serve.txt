# Slim runtime deps for free-tier hosting (Render free web service, ~512 MB RAM).
#
# Deliberately EXCLUDES the heavy ML stack — torch, transformers,
# sentence-transformers, pytorch-forecasting, pandas. With these omitted:
#   - email forensics (deterministic) works fully
#   - the trained email classifier (sklearn/LightGBM) works — set EMAIL_CLASSIFIER_PATH
#   - RAG retrieval works via the HashingEmbedder + lexical-stance fallback
#     (materially weaker than RoBERTa; the code logs this loudly and never
#      reports fallback quality as if it were the real model)
#   - anomaly detection works when a saved sklearn model is loaded
#   - TFT forecasting is unavailable (needs torch; the route says so honestly)
#
# For the full-quality stack (RoBERTa NLI, sentence-transformer embeddings), use
# requirements.txt on a host with >=2.5 GB RAM (e.g. Hugging Face Spaces free
# tier gives 16 GB), and swap the Dockerfile back.
